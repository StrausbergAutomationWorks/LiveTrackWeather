## Paasissutissat aallaaviat

| Aallaavik | Sumi | Pisariaqartitat |
|---|---|---|
| National Weather Service | USA | pisariaqartoqanngilaq |
| MET Norway | Norge, Svalbard, nunarsuaq tamaat (silap ilissinnaaneranut) | pisariaqartoqanngilaq |
| US Geological Survey | nunarsuaq tamaat | pisariaqartoqanngilaq |
| NASA FIRMS | nunarsuaq tamaat | kode akeqanngitsoq |
| MET Norway Frost | Svalbard, Jan Mayen | client ID akeqanngitsoq |

Kalaallit Nunaanni sila pillugu ilimagisat (**Forecast at …**) MET Norway-mit
pissarsiarineqartarput. USA-p kalerrisaarutai Kalaallit Nunaannut
tunngasuunngillat.
